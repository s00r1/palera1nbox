# palera1nbox

This repository hosts the tutorial and resources for palera1nbox v2.0.0.

## Installation
1. Download `palera1nbox.zip` or your desired release from the [Releases](https://github.com/some_repo/releases) page.
2. Extract the archive to a directory of your choice.
3. Open `index.html` in your preferred web browser. An internet connection is required since p5.js is loaded from a CDN.

### Automated Setup (Experimental)
Run the `install_palera1nbox.sh` script on your NanoPi to install common dependencies. Manual configuration steps such as enabling I2C via `armbian-config` are still required.

## Usage
- Follow the on-screen instructions provided in the webpage to build your own palera1nbox.
- A detailed tutorial is also available at [palera1nbox.s00r1.com](https://palera1nbox.s00r1.com).
